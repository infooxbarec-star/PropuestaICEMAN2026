La pieza central · Catálogo consultivo

Un catálogo pensado para generar conversación, no para publicar precios.

Los productos se muestran de forma ordenada para que el cliente entienda qué ofrece MAYSO y pueda consultar de inmediato. Esto permite manejar precios variables por volumen, disponibilidad, presentación, cliente recurrente o condiciones comerciales.

Recomendación: no mostrar precios públicos en productos cárnicos si estos dependen de stock, peso, volumen o acuerdos comerciales. La web debe abrir la conversación y el equipo de MAYSO cierra la cotización.
